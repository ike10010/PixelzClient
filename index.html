WHY PIXELZ

Crafted like a premium client. Free forever.

Mixin-based, GPL-3.0 compliant, event-driven — the same architecture as Pixelz & Wurst.

◈

ClickGUI — Pixel Perfect

Right Shift to open. Category panels, header colors, enabled 0xFF2A2A6E bar, click with sound, right-click to expand. Sorted alphabetically.

GUI: 6 panels • Draggable • 52 modules
⚙

Config That Persists

JSON save at config/pixelz/config.json. Stores enabled & key per module. Auto-save on toggle, game close, shutdown hook.

FabricLoader.getConfigDir()/pixelz
⌘

Commands & Keybinds

/pixelz help, list, toggle <module>. Every module rebindable. Default hotkeys: F, G, R, K, N, Right Shift.

/pixelz toggle fly • /pixelz toggle nuker
▦

Mixin Injection

No Mojang code shipped. Hooks via Keyboard, ClientPlayer, InGameHud, WorldRenderer, Entity, Lightmap. Event-forwarding like Pixelz.

MixinKeyboard → ModuleManager.onKey
◉

HUD — Watermark + ArrayList

Via MixinInGameHud. Watermark “Pixelz v1.1.4 | 1.21.11” + sorted ArrayList of enabled modules. Like Pixelz HUD.

MixinInGameHud + ClientTickEvents

GET STARTED

Install in 60 seconds

Requires Java 21, Minecraft 1.21.11, Fabric Loader ≥0.19.3

Download .jar
1

Install Fabric Loader

Download installer from fabricmc.net/use. Select 1.21.11. Or use Prism / MultiMC.

fabricmc.net/use →
2

Install Fabric API

Download fabric-api 0.141.6+1.21.11 and place in mods/.

modrinth.com/fabric-api →
3

Drop Pixelz .jar

Move pixelz-client-1.1.4.jar into .minecraft/mods/. Launch Fabric profile. Press Right Shift.

.minecraft/mods/pixelz-client-1.1.4.jar
Build from source
git clone https://github.com/your-repo/pixelz-client.git
cd pixelz-client
./gradlew build          # → build/libs/pixelz-client-1.1.4.jar
./gradlew runClient      # launch test client
./gradlew genSources     # decompile for IDE
