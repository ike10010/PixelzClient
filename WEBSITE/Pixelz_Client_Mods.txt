 PERFORMANCE MODS (4)
============================================================
 - FPSBoost: ParticlesMode.MINIMAL + CloudRenderMode.OFF + FAST graphics + no entityShadows + worldRenderer.reload() => +30% FPS, Sodium-compatible
 - EntityCulling: Cull distant (>64) + behind wall entities, reduces render calls
 - FastRender: DistortionEffectScale 0.0 + FovEffectScale 0.0 => less GPU strain
 - NoLag: Aggregated - particles minimal + noFireOverlay/hurtcam/weather logic
 Recommended extra: Add Sodium 0.6+1.21.11, Lithium 0.14+, FerriteCore, Starlight to mods/ alongside Pixelz for max FPS (all Fabric, compatible).

============================================================
 Keybind System
============================================================
 - Default ClickGUI: Right Shift (RShift)
 - Combat hotkeys: F (Fly), G (Speed), R (KillAura), K (ESP), N (Scaffold)
 - All modules rebindable via config/pixelz/config.json (key field)
 - Toggle via ClickGUI or /pixelz toggle <module>

============================================================
 Commands (in-game, client-side)
============================================================
 /pixelz help                 - Show help
 /pixelz list                 - List all 52 modules with enabled state
 /pixelz toggle <module>      - Toggle e.g. /pixelz toggle spider

============================================================
 Config & Storage
============================================================
 File: config/pixelz/config.json (FabricLoader.getConfigDir()/pixelz)
 Stores: enabled, key per module
 Auto-save: on toggle, on game close, shutdown hook

 Mixins Implemented
============================================================
 - MixinKeyboard              -> ModuleManager.onKey
 - MixinClientPlayerEntity    -> tick / tickMovement (NoSlow, SafeWalk)
 - MixinInGameHud             -> HUD ArrayList + Watermark
 - MixinWorldRenderer         -> onWorldRender(tickDelta) via getTickProgress(true)
 - MixinMinecraftClient       -> tick + save on close
 - MixinEntity                -> Velocity pushAwayFrom / addVelocity
 - MixinLightmapTextureManager-> FullBright lightmap
